# J-Planet モバイル・マイページ再現設計

更新日: 2026-08-10

## 目的

SAZO のモバイル Web 版マイページを参照し、録画で確認できる画面構成、遷移、スクロール、固定要素、空状態を J-Planet モックへ忠実に再現する。

再現対象の基準動画:

`/var/folders/f9/g75lkj552h7dv5fxlp1ztx040000gn/T/TemporaryItems/NSIRD_screencaptureui_9ghJeP/画面収録 2026-08-10 16.17.32.mov`

## 決定事項

- SAZO の情報設計、画面配置、遷移、固定ヘッダー、固定下部ナビ、固定アクションボタンを再現する。
- ロゴ、社名、ブランド配色は J-Planet に置き換える。
- 下部ナビ中央は既存のプロダクト方針を維持し、「検索」ではなく「エージェント」とする。
- モック内の操作で完結させ、外部サービスや本番決済・会員 API には接続しない。
- 実装対象はマイページ一覧だけではなく、録画内で遷移した関連画面を含む。

## ビジュアル仕様

- 基準幅は録画相当の 345 CSS px とし、341 px と 440 px でも崩れないことを確認する。
- 背景は白を主面とし、セクション間に薄いグレーの帯または罫線を置く。
- ヘッダーは白、下境界に細い影を付け、スクロール中も上部へ固定する。
- 本文は左右 14〜18 px の余白を基準とする。
- 文字色は J-Planet のネイビー、強調・選択状態は桜色を使用する。
- 行項目は左に線画アイコン、中央にラベル、右にシェブロンを配置する。
- 空状態は録画と同じく余白を広く取り、中央へ短い案内文を置く。
- 下部ナビは白い固定面、上部角丸、軽い影を持つ。
- チャットボタンは本文右下に浮かせ、下部ナビと干渉しない位置へ固定する。

## インタラクション

- 各行は行全体をタップ領域とする。
- 戻る操作は直前のマイページまたは関連一覧へ戻る。
- ホームアイコンはホームへ戻り、カートアイコンは既存のカート挙動を維持する。
- タブ、フィルター、通知トグルは選択状態を即時に反映する。
- フォーム保存、クーポン登録、住所追加はバックエンドへ送信せず、モックとして決定的に動作する。
- 画面遷移後は原則としてページ上端へ移動する。
- `prefers-reduced-motion` では遷移アニメーションを抑制する。

## データと文言

- 録画で確認できる会員名、ポイント数、クーポン数、空状態の件数を初期値として再現する。
- SAZO の社名、ロゴ、サービス名は表示しない。
- J-Planet のロゴ、社名、既存のブランドトークンを利用する。
- 日本語表示を基準とし、既存 i18n 構造へキーを追加する。既存言語ファイル間のキー整合を維持する。

## 実装境界

- マイページ関連の view/model、画面コンポーネント、局所 CSS、翻訳、fixture、テストを対象とする。
- ホーム画面のヒーロー、バナー、カテゴリ、商品レールの構造は変更しない。
- 認証フローは既存のローカルモックを利用し、認証仕様そのものは変更しない。
- 外部 URL、外部 API、決済処理、カード保存、住所保存は実装しない。

## アクセシビリティ

- アイコンボタンへ説明可能な `aria-label` を付ける。
- タブは `tablist` / `tab` と `aria-selected` を使用する。
- トグルは `role="switch"` と `aria-checked` を使用する。
- フォームラベルと入力欄を関連付ける。
- キーボードフォーカスを J-Planet の桜色アウトラインで表示する。
- 固定要素が本文や送信ボタンを覆わないよう safe-area を考慮する。

## 検証条件

1. 録画に現れる全画面へローカル操作で遷移できる。
2. 341 px、345 px、440 px の各幅で横スクロールが発生しない。
3. 固定ヘッダー、下部ナビ、チャット、固定アクションが重ならない。
4. マイページの表示順、余白、罫線、アイコン位置が録画と一致する。
5. 全翻訳ファイルのキー構造が一致する。
6. unit、typecheck、lint、build、モバイル E2E、画面キャプチャが通る。
7. マイページ関連の変更だけが差分に含まれ、既存ホーム再現を壊さない。
