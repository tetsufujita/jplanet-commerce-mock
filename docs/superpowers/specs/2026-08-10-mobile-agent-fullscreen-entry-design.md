# J-Planet モバイルAI入口・専用エージェント画面 デザイン仕様

更新日: 2026-08-10

## 目的

SAZOのモバイルホームが持つ、見慣れた「検索から商品を探す」導線を土台にしながら、J-Planetの中心機能が越境EC AIエージェントであることを最初の画面で伝える。

ホーム上の検索操作ではボトムシートを開かない。URL、画像、商品名のいずれからでも専用エージェント画面へ移動し、そこで相談を開始できる構造にする。

## 承認済みの方針

採用するのは、既存の `agent-hub` を専用エージェント画面として拡張する方式である。

比較した案は次のとおり。

1. **専用エージェント画面へ統合（採用）**
   - ホームのAI検索入口から `agent-hub` に遷移する。
   - URL、画像、商品名の入力を専用画面上に常設する。
   - 最近の相談、最近見た商品、人気キーワードを同じ画面に残す。
   - SAZO型の検索体験を維持しながら、J-Planetの独自性を最も明確にできる。
2. **既存ボトムシートを拡張**
   - 変更量は少ないが、画面が狭く、検索履歴や商品候補とつながりにくい。
   - ユーザーが指定した「検索からエージェント画面へ移動」に合わないため不採用。
3. **ホーム上に大型AIカードを展開**
   - AI機能は目立つが、SAZOホームの再現度と商品カタログの可視領域が下がる。
   - 今回はSAZO型を基準に微調整するため不採用。

## 対象範囲

### 対象

- モバイルホームの2段ヘッダー
- ヒーローに重なるAI検索入口
- 専用 `agent-hub` 画面の入力領域
- URL、画像、商品名の入力モード
- 画像選択とローカルプレビュー
- エージェント画面内の既存履歴、商品、人気キーワード、フッター
- 下部ナビゲーションのエージェント選択状態
- 日本語、ポルトガル語、英語の表示文言

### 対象外

- AI検索API、画像認識API、商品取得APIとの接続
- 実際のファイルアップロードや永続保存
- 商品詳細、カート、決済の仕様変更
- デスクトップ版の検索体験の再設計
- 既存の商品・ランキングfixtureの内容変更

## 画面構成

### 1. モバイルホームヘッダー

SAZO参照動画と同じく、ヘッダーを上下2段で表示する。J-Planetのロゴ、紺、桜色は維持する。

- 1段目: J-Planetロゴ、言語、検索、カート
- 2段目: ホーム、サービス紹介、人気ブランド、カテゴリー、レビュー、ヘルプ、お知らせ
- 2段目は1行固定の横スクロールとし、指で左右に移動できる
- スクロールバーは見せない
- 端の項目を部分的に切って表示し、続きがあることを視覚的に示す
- ホーム選択時は桜色の文字と下線を使う
- ヘッダー下端にはSAZO参照と同程度の角丸と薄い影を付ける
- ヒーローは2段目の直下から開始し、不要な空白を入れない

### 2. ホームのAI検索入口

ヒーロー下端に重なる白い検索ピルを維持し、検索UIの親しみやすさとAI機能を両立する。

- 左側: 桜色のSparklesアイコンと小さな `AI` バッジ
- 中央: `URL・画像・商品名をAIに相談`
- 右側: 画像追加を示すImagePlusアイコン
- ピル本体を押すと `agent-hub` へ移動し、標準の相談入力を選択する
- 右側の画像アイコンを押すと `agent-hub` へ移動し、画像入力モードを選択した状態にする
- ホーム上ではボトムシートを開かない
- 画像アイコンの操作がピル本体の操作へ二重伝播しないようにする

### 3. 専用エージェント画面

専用画面はボトムシートではなく、通常のページとして表示する。

#### コンパクトヘッダー

- 戻るボタン
- AI検索フィールド風のランチャー
- ホームボタン
- カートボタン
- ヘッダーは画面上部に固定し、本文はその下からスクロールする

#### AIイントロ

- J-Planetの桜アイコンと `J-Planet AIエージェント`
- 説明: 日本の商品探し・購入からブラジルへの配送までAIが支援することを短く伝える
- SAZO検索画面を参考に、次の2点を短いステップとして表示する
  1. 日本の商品URLまたは画像を送る
  2. 商品名や希望条件だけでも相談できる

#### 統合コンポーザー

3つのモードを常時表示する。

- `URLを貼る`
- `画像を追加`
- `商品名で相談`

モード選択に応じてプレースホルダーを変えるが、入力領域は同じカード内に保つ。

- URL: `日本の商品URLを貼り付けてください`
- 画像: 選択ボタン、選択済み画像のサムネイル、ファイル名、削除ボタン
- 商品名: `欲しい商品名や条件を入力してください`
- 送信CTA: `AIに探してもらう`
- URLまたは商品名が空で、画像も未選択の場合はCTAを無効化する
- URL、文字列、画像のいずれかが存在すればCTAを有効化する
- モックのためCTAはネットワーク送信せず、相談受付状態を画面内に表示する

#### 画像入口の挙動

- ホームの画像アイコンから遷移した場合、まずエージェント画面を表示する
- エージェント画面で画像モードを選択状態にする
- 画面表示後にファイル選択を開くことを試みる
- ブラウザが自動オープンを制限した場合やユーザーがキャンセルした場合も、同じ位置に明確な `画像を選択` ボタンを残す
- ファイル入力は `accept="image/*"` とする
- 非画像ファイルは受け付けず、入力領域内にエラーを表示する
- 選択画像はブラウザ内のObject URLでプレビューし、差し替えまたは削除できる
- Object URLは差し替え、削除、アンマウント時に解放する

### 4. 既存コンテンツとの接続

統合コンポーザーの下には、既存 `agent-hub` の情報を順番に残す。

1. 最近の相談
2. 最近見た商品
3. 人気検索キーワード
4. 会社・規約フッター

最近の相談と最近見た商品にある削除操作は維持する。人気検索キーワードを押すと、商品名モードにキーワードを入れた状態へ移し、ページ上部のコンポーザーへスクロールする。

下部ナビゲーションは常時表示し、エージェント画面では `エージェント` を選択状態にする。

## コンポーネント境界

既存構造を使い、責務を次のように分ける。

- `HomeView`
  - ホームのAI入口を描画する
  - 標準相談または画像相談の遷移intentを送る
- `model`
  - `agent-hub` への遷移と初期入力モードを保持する
  - 入力中のファイル自体は保持しない
- `MobileAgentHubView`
  - 専用画面全体を組み立てる
  - 初期intentを受け取り、統合コンポーザーと既存セクションを配置する
- `AgentComposer`
  - 3モード、入力状態、画像プレビュー、CTA、受付状態を担当する独立コンポーネントに分離する
- `SazoShell`
  - モバイルヘッダー、横スクロールナビ、下部ナビの選択状態を担当する
- `AgentComposerSheet`
  - 今回のホームと `agent-hub` からは呼ばない
  - 他の既存導線が必要とする場合に備え、今回の変更では削除しない

## 状態とデータフロー

```text
ホームのAI検索ピル
→ agent-hub / compose intent
→ 専用画面を表示
→ 標準相談モード

ホームの画像アイコン
→ agent-hub / image intent
→ 専用画面を表示
→ 画像モードを選択
→ ファイル選択を試行
→ 選択画像をローカルプレビュー

人気キーワード
→ 商品名モード
→ キーワードを入力
→ コンポーザーへスクロール
```

画面遷移後に同じ画像intentが再実行されないよう、初期intentは一度消費したら標準状態へ戻す。

## 視覚仕様

- 背景は白を主役にする
- 主要色はJ-Planet Navy、補助色はSakura Pink
- AI機能にはSparklesを使うが、装飾を増やしすぎない
- 角丸はホーム検索ピルとコンポーザーカードで統一する
- 入力のフォーカスはブラウザ既定の赤枠を使わず、桜色の薄いリングで示す
- 341px、390px、440pxで横方向の欠けや意図しないスクロールを発生させない
- iOSの固定下部ナビとコンポーザーが重ならないよう、本文下端にsafe-areaを含む余白を確保する

## アクセシビリティ

- ピル本体と画像アイコンは別々のアクセシブル名を持つ
- アイコンだけの操作には `aria-label` を付ける
- モードはキーボードで選択でき、選択状態を `aria-pressed` で示す
- ファイル入力はラベルから操作できる
- サムネイルには選択したファイルを識別できる代替テキストを付ける
- エラーと相談受付状態はスクリーンリーダーへ通知する
- `prefers-reduced-motion` では自動スクロールや画面遷移の動きを最小化する

## テスト方針

### Unit

- ホーム検索ピルが `agent-hub` の標準相談intentを送る
- ホーム画像アイコンが `agent-hub` の画像intentを送る
- ホーム操作で `open-agent` が呼ばれない
- 画像intentで画像モードが選択される
- URL、商品名、画像の有無に応じてCTAの有効状態が変わる
- 画像選択、差し替え、削除、Object URL解放を確認する
- 人気キーワードが商品名モードへ反映される
- モバイルナビに7項目が存在する

### E2E

- 341pxと440pxでホームから専用エージェント画面へ遷移する
- ホーム画像入口から専用画面へ移動し、画像モードになる
- ファイル選択後にサムネイルが表示される
- エージェント画面で下部ナビのエージェントが選択状態になる
- モバイル2段目ナビを指相当の操作で左右スクロールできる
- ボトムシートがホーム検索操作では表示されない
- デスクトップ版の既存検索、ヘッダー、商品導線が退行しない

### Visual QA

- 参照スクリーンショットと341px幅で比較する
- 2段ヘッダー、ヒーロー、AI検索ピル、カテゴリショートカットの縦位置を確認する
- エージェント画面でコンポーザー、履歴、商品、ランキングが順番どおりに表示されることを確認する
- 実画像を1枚選び、プレビューと削除後の状態を目視する

## 完了条件

- ホーム検索操作でボトムシートが開かない
- ホームの検索ピルと画像入口が専用エージェント画面へ遷移する
- 画像入口では、エージェント画面表示後に画像選択へ進める
- 専用画面だけでURL、画像、商品名の3方式を開始できる
- 既存の履歴、最近の商品、人気キーワード、フッターが失われない
- J-Planetの色とロゴを保ちながら、SAZO参照のモバイル密度と操作感に近づく
- 341px、390px、440pxで主要操作が欠けず、下部ナビと重ならない
- Unit、E2E、lint、typecheck、build、Visual QAが完了する
