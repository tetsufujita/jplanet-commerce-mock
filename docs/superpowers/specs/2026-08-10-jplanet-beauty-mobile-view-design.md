# J-Planet BEAUTY モバイル専用ビュー設計

更新日: 2026-08-10

## 目的

ホームのショートカット「コスメ」から、参照動画
`画面収録 2026-08-10 17.21.56.mov` と同じ情報構造・密度・操作感を持つ
モバイル専用の BEAUTY トップへ遷移できるようにする。

参照元のブランド表記はそのままコピーせず、ヘッダーだけ
`J-Planet BEAUTY` に置き換える。検索はAIエージェント導線ではなく、
BEAUTY画面内で入力・実行・結果確認まで完結させる。

## 採用方式

既存の汎用カタログ画面へ条件分岐を追加せず、新しい `beauty` ビューと
専用コンポーネントを追加する。

この方式を採る理由:

- 参照動画は通常カタログと異なる専用ヘッダー、ヒーロー、検索、商品レール、
  トレンド順位を持つ。
- 既存カタログのレイアウトや検索導線を変更せずに再現できる。
- BEAUTY画面内の検索状態とカテゴリーチップ状態を独立してテストできる。
- 商品カードから既存の商品詳細遷移だけを再利用できる。

## 対象範囲

### 含む

- ホームの「コスメ」ショートカットから `beauty` ビューへの遷移
- J-Planet表記へ置き換えた専用BEAUTYヘッダー
- ページ内で直接入力できる検索フォーム
- 横スワイプ可能な美容カテゴリーチップ
- チップごとの商品レールと短いスケルトン表示
- 「今話題のJ-Beautyトレンド」の商品レールと順位リスト
- 既存の商品詳細画面への遷移
- 固定下部ナビゲーションとの共存
- 341pxおよび440px幅でのモバイル再現検証

### 含まない

- 本番検索APIやAI検索APIとの接続
- 新しい商品詳細・カート・決済仕様
- デスクトップ専用BEAUTYページの新規デザイン
- 既存のエージェント画面・AIボトムシートの変更
- 管理画面からの商品編集機能

## 画面遷移

```text
ホーム
  └─ コスメをタップ
       └─ beauty ビュー
            ├─ 検索欄へフォーカス → 同じ画面で入力
            ├─ Enter / 緑の検索ボタン → 同じ画面で商品を絞り込み
            ├─ カテゴリーチップ → 同じ画面で商品群を切り替え
            └─ 商品カード → 既存の商品詳細
```

検索欄を押しても `agent-hub` へ遷移せず、`open-agent` もdispatchしない。

## レイアウト

### 1. 専用ヘッダー

- 画面上部に固定する。
- 1段目は左から `J-Planet` ロゴ、`BEAUTY` ラベル、言語、検索、カート。
- 2段目は `コスメ`、`ヘルプ`、`お知らせ`。
- `コスメ` を選択状態にし、J-Planetの桜色で下線を表示する。
- 角丸、薄い影、高さ、余白、アイコンサイズは参照動画に合わせる。
- 既存のホーム用2段ヘッダーはBEAUTYビューでは表示しない。

### 2. ヒーロー

- 小さなストアバッジを中央上部へ置く。
- 見出しはJ-Planet向けに `これからは J-Planet で探す` とする。
- 日本の商品をブラジルへ届ける説明文を見出し直下へ置く。
- 白背景を維持し、参照動画と同じ大きな黒文字、中央揃え、縦余白にする。

### 3. ページ内検索

- ヒーロー直下に横長の白い検索フィールドを置く。
- 左側は通常の `input[type="search"]` とし、プレースホルダーは
  `キーワードまたはURLを入力`。
- 右端に緑色の円形検索ボタンを配置する。
- 入力欄のタップでは同一画面に留まり、ソフトウェアキーボードを開く。
- Enterまたは検索ボタンで検索語を確定し、画面内の商品レールを絞り込む。
- 検索語が空の場合は全件表示へ戻す。
- 一致商品がない場合は、検索欄直下に簡潔な空状態を表示する。
- 本番検索APIは使わず、モックの商品名・ブランド・カテゴリー名に対する
  大文字小文字を区別しない部分一致で動作させる。

### 4. 補助コピー

- 検索欄左下から伸びる手描き風矢印を表示する。
- `J-Planetで、日本の人気商品をリアルタイム検索！` を配置する。
- 矢印は画像ではなく専用SVGで再現し、拡大時もぼやけないようにする。

### 5. カテゴリーチップと商品レール

- 見出しは `日本のショップから欲しい商品を探してみよう！`。
- チップは横方向のネイティブスクロールとし、指でスワイプできる。
- 初期選択は `スキンケア`。
- 参照動画で確認できる順序を使う:
  `スキンケア`、`マスクパック`、`クレンジング`、`日焼け止め`、
  `メイクアップ`、`メンズケア`、`香水`、`ヘアケア`。
- 選択中のチップは黒背景・白文字、その他は白背景・細いグレー枠。
- チップ変更時に約500msの3列スケルトンを表示してから商品を差し替える。
- 商品はモバイルで3列が見える横レールとし、指で横スワイプできる。
- 各カードは画像、販売元バッジ、2行の商品名、価格、保存アイコンを持つ。

### 6. J-Beautyトレンド

- 見出しは `今話題のJ-Beautyトレンド`。
- 上段に3列の商品レールを置く。
- 下段に順位、キーワードを縦並びで表示する。
- 上位3件の順位は桜色、それ以外は濃紺とする。
- 商品カードを押した場合のみ既存の商品詳細へ遷移する。

### 7. 下部ナビゲーション

- 既存の固定下部ナビを表示し続ける。
- BEAUTYビューでは特定タブを選択状態にせず、ホームへ戻る操作は
  下部ナビのホームから行える。
- コンテンツ末尾にはナビ高さとsafe-areaを含む余白を確保する。

## コンポーネント境界

- `BeautyView`: 専用ページ全体と検索・カテゴリ状態を管理する。
- `BeautyHeader`: 専用2段ヘッダーだけを担当する。
- `BeautySearch`: 制御された入力、submit、空状態を担当する。
- `BeautyCategoryRail`: チップの選択と横スクロールを担当する。
- `BeautyProductRail`: 商品カード、スケルトン、横スクロールを担当する。
- `BeautyTrendList`: トレンド商品と順位リストを担当する。
- `beautyFixtures`: 商品、カテゴリー、トレンドのモックデータを保持する。

BEAUTY固有の状態を既存 `HomeView` や `CatalogView` へ混在させない。

## 状態とデータフロー

- `SazoView` に `beauty` を追加する。
- ホームの `ShortcutRow` はdispatchを受け取り、`cosmetics` のみ
  `{ type: "navigate", view: "beauty" }` を送る。
- 検索文字列、確定検索語、選択チップ、短時間のloading状態は
  `BeautyView` 内のローカル状態とする。
- 商品詳細遷移は既存の `open-product` actionを使う。
- URLのQA指定で `view=beauty` を開けるよう、既存のQA view集合にも追加する。

## エラー・空状態

- 画像読み込みに失敗したカードは、カード寸法を保ったプレースホルダーを表示する。
- 検索結果が0件でもヘッダー、検索欄、カテゴリーチップを維持する。
- ローディング中に別チップを押した場合は、最後に選んだチップだけを反映する。
- 横スワイプは縦スクロールを妨げないよう `touch-action: pan-y` と
  ネイティブ横スクロールを組み合わせる。

## アクセシビリティ

- 検索欄は視覚ラベルまたは非表示ラベルと関連付ける。
- 検索ボタン、保存ボタン、カート、言語、戻る操作にaria-labelを付ける。
- チップは `aria-pressed` で選択状態を表現する。
- フォーカスリングはJ-Planet桜色を使い、ブラウザー既定の赤枠は出さない。
- 商品画像には商品名をaltとして設定する。

## テスト

### Unit

- 「コスメ」押下で `beauty` へ遷移する。
- BEAUTY画面で検索欄へ直接入力でき、`open-agent` が送られない。
- Enterと検索ボタンが同じ絞り込み結果になる。
- 空検索で全件、該当なしで空状態になる。
- カテゴリーチップ変更で選択状態と商品群が変わる。
- 商品カード押下で既存 `open-product` が送られる。
- 専用ヘッダー、トレンド順位、固定下部ナビが存在する。

### E2E / Visual

- 341pxと440px幅でホームからコスメへ遷移できる。
- 検索欄をタップしてもURL/viewが `beauty` のまま入力できる。
- カテゴリーチップと商品レールを指操作で横スワイプできる。
- スケルトン表示後、最後に選んだカテゴリーの商品へ切り替わる。
- 参照動画の主要チェックポイントをスクリーンショット比較する:
  初期ヒーロー、初期商品レール、チップ変更中、チップ変更後、
  トレンド順位リスト。
- デスクトップ既存ホーム・カタログ・商品詳細の回帰テストを通す。

## 完了条件

- ホームのコスメから1タップで専用BEAUTYビューへ移動できる。
- 検索欄が同一画面内で入力・検索でき、エージェント画面を開かない。
- 参照動画のヘッダー、ヒーロー、検索、チップ、商品レール、トレンド、
  固定下部ナビの配置と操作が341pxおよび440pxで再現されている。
- J-Planetロゴとブランド色を維持し、`J-Planet BEAUTY` と表示される。
- unit、lint、typecheck、build、mobile E2E、visual captureが成功する。
