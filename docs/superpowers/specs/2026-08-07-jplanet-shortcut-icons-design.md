# J-Planet配色・ショートカットアイコン デザイン仕様

## 目的

SAZO由来の配色をJ-Planetブランドへ置き換え、`/sazo-commerce-mock/`配下の全ページを白基調のJ-Planetテーマに統一する。同時に、ホーム画面の「SAZO特集／限定／フリマ／コスメ／K-POP」を再設計し、低解像度PNG由来のぼやけをなくす。既存画面の軽快さを保ちながら、細い線画ではなく、丸みのある塗り面で構成したポップな見た目に統一する。

## ブランドパレット

提供されたJ-Planetロゴから抽出した次の色を正典とする。

| 用途 | 色 | 値 |
|---|---|---|
| ブランドネイビー | J-Planetロゴ文字 | `#1f3864` |
| ディープネイビー | 桜マークの輪郭・本文強調 | `#1f2e4f` |
| 桜ピンク | 桜の花びら・アクセント | `#fea2ac` |
| メインサーフェス | ページ、ヘッダー、商品カード | `#ffffff` |
| ソフト桜 | 選択・装飾の淡い背景 | `#fff4f5` |
| ソフトブルー | 補助セクションの淡い背景 | `#f3f6fb` |

## 全ページの配色ルール

- ページ背景、ヘッダー、検索フォーム、商品カードの主面は白を維持する。
- 主要ボタン、選択中のナビゲーション、重要なリンクはブランドネイビーを使う。
- バッジ、通知、ホバー、キャンペーン装飾は桜ピンクを使う。
- 本文はディープネイビーを基本とし、補助文はネイビーを薄めたグレーを使う。
- 淡い背景が必要な場所だけソフト桜またはソフトブルーを使い、画面全体を有彩色で塗らない。
- 値引き、成功、警告、エラーなど意味を持つ状態色は判別性を優先し、必要な範囲で維持する。
- 旧SAZOピンクや旧SAZOロゴ色を参照するハードコード値は、表示上残さない。
- ホーム、商品一覧、各ディレクトリ、レビュー、アカウント、認証、サービス紹介、キャンペーンを同じ配色原則へ揃える。

## ビジュアルルール

- J-Planetの桜ピンク、ネイビー、白を基本色にする。
- 限定、フリマ、コスメ、K-POPは細いアウトライン主体にせず、太い塗り面と丸い角で構成する。
- 各アイコンは同じ視覚サイズ、重心、余白に揃える。
- 白い角丸タイルと柔らかい影は維持し、アイコンだけが浮いて見えないようにする。
- `new`は小さな桜ピンクのバッジとしてタイル内に収める。
- ラベルは現在の位置と文字サイズを維持し、「SAZO特集」だけを「J-Planet特集」へ変更する。

## 実装方針

- J-Planetパレットを共通CSSカスタムプロパティとして定義し、既存コンポーネントの色指定をそこへ集約する。
- 既存の内部クラス名はルーティングや挙動を壊さないため維持するが、画面へ出る色はJ-Planetトークンから供給する。
- 旧SAZO色のハードコード箇所を洗い出し、ブランド用途と意味色を分けて置換する。
- 桜マークは `/Users/fujitatetsu/Downloads/J-Planet-staging-sakura-mark.png` を原典とし、公開用アセットへ複製する。
- 残り4アイコンはインラインSVGの塗り図形として実装し、画面密度にかかわらず鮮明に表示する。
- ショートカットデータは画像URLではなくアイコン種別を持ち、表示コンポーネントが対応するSVGを描画する。
- 既存のショートカット選択動作と遷移は変更しない。
- 画像読み込みに失敗した場合もタイルの大きさとラベル位置は崩さない。

## 検証

- ブランドトークンがロゴ原典の `#1f3864`、`#1f2e4f`、`#fea2ac` と一致することを自動テストする。
- 全ページの主要サーフェスが白基調を維持し、旧SAZOピンクが主要UIに残っていないことを実ブラウザで確認する。
- 5項目のラベル、順序、クリック動作を既存テストで維持する。
- 「J-Planet特集」とJ-Planet桜マークが表示され、旧SAZO特集画像が使われないことを自動テストする。
- 4つのカテゴリがラスター画像ではなくSVGで描画されることを自動テストする。
- デスクトップとモバイルの実ブラウザで、ぼやけ、サイズ差、タイルからのはみ出しがないことをスクリーンショットで確認する。

## 対象外

- ショートカットから遷移する各ページの内容変更。
- ショートカット以外の文章に含まれるSAZO表記の全面的な書き換え。
- ヘッダー、カルーセル、商品カードのレイアウト変更。
