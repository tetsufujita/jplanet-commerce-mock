## ★ Andes が最も参考にすべき 5 つ（議論の結論）
1. **Mercado Libre IR** — 事業最近接（LatAm commerce+fintech）＋投資家向けに長期成長を「5 charts/ecosystem 図」で着地。**投資家章の本命手本**。
2. **dLocal** — 新興国クロスボーダー決済 platform でほぼ同型。「1 API で複雑さ」＋地域 coverage を interactive＝**日伯⇄LATAM・通関/税/法スタックの地理表現**に直結。
3. **Sierra** — 「Built on＝基盤化」宣言＋**results を専用章に隔離**＝Andes の宣言型 hero＋EC 証拠隔離と構造一致。
4. **CloudWalk** — **伯発 agentic commerce の実在事例**＋複数ブランドの章分け＝持株グループ(Andes Inc/BR/J-Planet)×agentic の二重の近さ。
5. **Linear** — 事業は遠いが **anti-slop premium の品質基準**（type と余白、accent は面積で殺す＝Crimson pin-point）。

**組み合わせ方**: 構成骨格=Stripe（機能カード＋巨大数値）、copy トーン=Anthropic（謙虚・射程長）、proof 密度=Ramp。→ 「宣言 → 具体数値 → 地味な実装の着地」を満たす。
