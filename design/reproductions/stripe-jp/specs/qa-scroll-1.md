## 補足メモ

### クローン全体のスクロール速度差について
クローン (68f/22.5s) の方が原本 (79f/26.4s) より約 15% 速くスクロールが終わる。ページ全長が短いか、スクロール速度設定が異なる。後続のフレームで原本がフッター到達後も 15f 程度余分に残っているのは、ページ終端での録画スクリプトの待機時間の差と考えられる。

### ambient アニメの全般的傾向
クローンは **静的コンテンツの配置・テキスト・レイアウト** は原本と非常に高精度に一致している。差分の大部分は **ambient / continuous アニメ**（odometer カウンター・marquee・背景グラデーション動き・ウェーブ・接続線 draw）が停止していることに集約される。これらは JavaScript の requestAnimationFrame ループまたは CSS animation が動いていない可能性が高い。

### 欠落要素（重要）
- `supabase` カード（スタートアップカルーセル 4 枚目）— クローンで視認できず（#7）
