## hover の見え方まとめ（再現実装向け）

- **expand ボタン ⤢ の hover**: 通常時 = 透明背景＋薄グレーの対角矢印。hover 時 = 角丸スクエアが青紫（indigo/blurple）で塗りつぶされ矢印が白反転。in/out とも 1 frame（≤333ms）で完了する短い fade。カード本体の lift / shadow / scale 変化は **観測されず**（カードは動かない、ボタンだけ変化）。
- hover 解除の戻りアニメも同速・対称（frame 188 の エージェンティック ⤢ 消灯で確認）。
- カード内デモ（ticker / ロケール切替 / カード柄サイクル / グローブ）は hover と完全に独立して回る ambient loop。再現時は hover と切り離して実装する。

## 不確実な点

1. **マウスカーソル自体が全フレームで不可視**（キャプチャにカーソル非含有）。hover 位置は ⤢ ボタンの state 変化からの逆算であり、「カード全域 hover で ⤢ が点灯」なのか「⤢ 直上 hover のみで点灯」なのかは判別不能。
2. frames 191–200 はキャプチャ解像度が低く（縮小フレーム）、トークン集計値が「2,010,569,010」のままか別値（2,322,966,915 に見える瞬間あり）へ ticker したか読み取れない。
3. モーション #6（VISA ロゴが見えてくる動き）は、カード画像自身のアニメか scroll 連動 parallax かを 3fps では切り分けられない。
4. モーション #11（チャットデモの価格出現）は低解像度のため存在自体が未確定。
5. 各 crossfade の正確な duration / easing は 333ms サンプリングでは下限しか分からない（実測には devtools の Animations panel か高 fps 録画が必要）。
6. この区間に header megamenu の開閉は登場しない（megamenu は担当範囲外の前半フレームと推定）。
