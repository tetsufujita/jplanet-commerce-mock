## 不確実な点

1. **megamenu close（#4）と siblings 復帰（#6）の正確な duration**: いずれも1フレーム間隙（333ms）内で完結しており中間が撮れていない。実装時は Stripe 標準の 150–250ms を getComputedStyle / DevTools で実測すべき。
2. **「料金体系」hover の見た目変化**: hover 中（042–046）と通常時（047 以降）の輝度がほぼ同値（min 18–21）で、料金体系自身の hover 色変化は検出できなかった。「siblings が薄くなる」ことが実質の hover フィードバックの可能性。
3. **「サインイン」「営業にお問い合わせ」hover の背景色変化**: 縮小キャプチャのため、僅かな背景 tint（例: white→#f6f9fc）は検出不能。
4. **マウス座標**: カーソル非表示録画のため、滞在位置は要素の状態変化からの逆算。047–051 がサインイン hover である根拠は枠線/文字の濃化のみ。
5. **058 の header 橙染まり**: gradient canvas の ambient と判断したが、057→058 で変化が急。次 range（059〜）でスクロール開始やページ遷移が始まっている可能性があり、059 以降の担当と突合のこと。
6. **megamenu パネル切替（#2）の morph 詳細**: 3fps では「幅が連続的に伸縮するか」「コンテンツが左右スライドするか」までは分解できない。035 時点で新コンテンツがほぼ定位置のため、切替は速い（≤400ms）。
