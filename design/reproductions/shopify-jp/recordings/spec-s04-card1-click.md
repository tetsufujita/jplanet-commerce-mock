## ③ interaction 仕様（hover / click / 自動の各挙動）

### hover 挙動

**本家: なし**

- アイコンにカーソルを当てても、輝度・スケール・リング・接続線のいかなる変化も起きない
- cursor は通常の pointer（矢印）または十字カーソル（+）に変化する場面あり（ブラウザのデフォルト）
- `pointer-events: none` または `cursor: default` に相当

### click 挙動

**本家: なし（反応なし）**

- アイコンをクリックしても視覚的反応は観測されない
- scale-down（押下感）なし、リングなし、フラッシュなし
- 接続線のパルスもなし
- 商品カードの出現もクリック契機ではなく自動タイマー

### 自動ループ挙動

**A. アイコン点灯ループ: なし（前回 f4 解析との差異 ← 要注意）**

- 旧 spec（spec-s04-subcards.md）では「3.5s 周期の輝度パルスループあり」と記録
- 今回の f5 録画（6fps・60フレーム・9.94s）では **全フレームで全アイコンの輝度が完全一定**
- アイコン輝度変化 > 3 の差分: **0 件**
- 解釈: f4 録画での観察は**誤判定（JPEG 圧縮や 4fps の解像度不足による誤り）の可能性が高い**
- または点灯ループが存在しても f5 の録画タイミングでは周期的に点灯が全アイコン同輝度状態だった可能性
- **本仕様では「点灯ループなし」を暫定採用**（次回録画で再確認推奨）

**B. 商品カード自動出現サイクル**

```
タイミング（f5 録画からの実測）:
  - 出現: t ≈ 3.0s から fade-in 開始
  - 最大表示: t ≈ 3.17s〜3.83s（5 フレーム ≈ 0.83s）
  - フェードアウト開始: t ≈ 4.0s
  - テキスト消滅: t ≈ 4.0s〜4.83s（テキスト先に消え、画像のみ残る）
  - 画像がロゴへ吸い込み消滅: t ≈ 5.0s〜5.33s
  - 消滅完了: t ≈ 5.33s（出現から約 2.33s で完全消滅）

ループ周期: 録画内では 1 サイクルのみ観測 → 前回推定 8s が妥当
```

**商品カード消滅の 2 段階アニメ詳細:**

```
Phase 1（t=4.0〜4.83s, 約 0.83s）:
  - テキスト部分（商品名・価格テキスト）がフェードアウト
  - カードの白背景矩形も縮小開始
  - 商品画像サムネ（40×40px 角丸）は残存

Phase 2（t=5.0〜5.33s, 約 0.33s）:
  - 画像サムネがバッグロゴ方向（y≈261）へ上昇
  - 同時に縮小（スケールダウン）
  - ロゴ中心付近で消滅（「バッグに入る」演出）
  - 消滅時 y=257 ≈ ロゴ中心 y=261（± 4px）= 吸い込み先がロゴ中心に一致
```

### React 実装可能な粒度での仕様

```tsx
// 商品カード自動表示: 8s 周期（前回推定継続）、表示時間 1.5s（内訳: 完全表示 0.83s + フェード中）
// → 現実装(setTimeout 4750ms + setInterval 8000ms)はほぼ正確

// 商品カード出現: 現実装と一致
initial={{ opacity: 0, scale: 0.85, y: 8 }}
animate={{ opacity: 1, scale: 1, y: 0 }}
transition={{ duration: 0.35, ease: "easeOut" }}

// 商品カード消滅（2段階）— 現実装は単純 exit のみ → 要修正
// Phase 1: テキスト先フェード（カード全体の opacity を下げつつ）
exit={{ opacity: 0, scale: 0.9, y: -4 }}
// ★本家はテキストが先に消え、画像サムネが上昇してロゴへ吸い込まれる
// 実装方針: AnimatePresence exit に 2 段階 keyframe を使用
// または: テキスト div と画像 div を別 motion.div に分割し、
//   テキスト: exit={{ opacity: 0 }} transition={{ duration: 0.4 }}
//   画像: exit={{ opacity: 0, scale: 0.3, y: -80 }} transition={{ duration: 0.3, delay: 0.4 }}
// 画像の y: -80 = バッグロゴ方向（カード top=105, ロゴ top=207 → 差 102px を上昇）

// hover/click: 現実装に pointer-events-none は不要だが、アイコンへの onClick も不要
// アイコンへの hover/click 反応: 実装しない（本家も反応なし）

// 自動点灯ループ: 暫定的に実装しない（本家での確認が取れていないため）
// → useStageTimeline による輝度パルスを削除し、全アイコン常時同輝度に変更
```

## ⑤ 旧 spec との差異（spec-s04-subcards.md との対比）

| 項目 | 旧 spec（f4 録画・4fps） | 今回実測（f5 録画・6fps） |
|---|---|---|
| アイコン輝度パルスループ | **あり**（3.5s 周期、1 アイコン 500ms） | **なし**（全 60 フレームで輝度変化 0） |
| hover 反応 | 未調査 | **なし** |
| click 反応 | 未調査 | **なし** |
| 商品カード消滅 | 単純 fade-out（0.5s） | **2 段階**（テキスト先消え → 画像ロゴ吸い込み上昇） |
| 商品カード出現位置 | ロゴ右上 | ロゴ左上〜上（x=142〜325, y=105〜263） |
| 接続線のアクティブ反応 | パルスなし（線は静止）と記録 | 同様に変化なし（確認） |

**特記: アイコン点灯ループ**
旧 spec（f4, 4fps）での観察は「Pinterest から YouTube へ順に輝度アップが走る」としたが、f5（6fps）の精密解析では全 60 フレームで輝度変化ゼロを確認。
4fps 録画の低解像度 + JPEG 圧縮による輝度ノイズを点灯と誤認した可能性が高い。
**ただし本家がレスポンシブ状態や別デバイスで動作を変える可能性は排除できない。**
再確認が取れるまで「実装しない（常時通常輝度）」を暫定方針とする。

## サマリ（3 行）

**差分件数**: 6 件（P1〜P6）。うち要修正は P1（点灯ループ削除）+ P2（消滅 2 段階化）+ P3（接続線 active 削除）+ P6（通常輝度修正）の **4 件**。

**クリック挙動**: hover・click ともにアイコン/接続線への視覚的反応は**一切なし**。商品カードは自動タイマー（録画では t≈3.0s）で出現し、出現→テキスト先消え→画像がロゴへ吸い込みの 2 段階 ≈ 2.3s で消滅する。

**自動ループ有無**: アイコン点灯ループは今回録画（f5・6fps・9.94s）で**観測されなかった**（旧 f4 spec の「3.5s 周期ループあり」は誤判定の疑いが高く、暫定的に不実装へ変更を推奨）。商品カード出現サイクルのみ存在（周期 ≈ 8s、表示 ≈ 1.5s）。
