## モーション所見

### globe（回転・操作）
- **回転は 2 段階**: f028–034 = idle 自転（ゆっくり、日本が中央に留まる程度）→ f035–052 = **drag 操作**（日本→豪州→南極→反転→アジア復帰、約 90–100° を 3 秒 ≈ 30°/s）。
- 経路は**緯度方向が主**（南下→南極で滞留→北上）。自動演出ではなく手動 drag の挙動（速度ムラ・反転あり）。
- 質感: 濃紺の海 + teal の大陸 + 金色の都市光（夜景）。背景は星空パーティクル。

### 弧（arc）
- 描画方式: 白〜金のトレイルが**起点から伸び、頂点を越えて尾側から減衰して消える**（grow → fade-tail）。先端が最も明るい。
- 同時 5–10 本、新規発生は約 0.25–0.5s に 1 本ペース。**都市光の密集地帯（日本・豪州沿岸・東アジア）を起点に集中**。
- 高速回転中（f036–038）は平行な束状 streak に見える。f046 に大ループ軌道、f053–054 に密集バースト。

### tooltip
- 2 種をローテーション。様式 = 暗色半透明ピル + 細い teal 枠 + 左に丸アイコン + **緑のモノスペース字**。fade で出入り。
  - ①「数百万社 / SHOPIFYを利用するマーチャントの数」（店アイコン）: f030–034 下部中央、f052 に cursor 横へ再出現。
  - ②「$1,600,000,000,000 / 販売合計（現在も増加中）」（$ アイコン）: f035 下部 → f039–040 で**globe 上のアンカー点に追従して左上へ移動** → f052 で画面左端から退場。**world-anchored**（回転と一緒に動く）。

### cursor
- ページ標準 cursor を**ピンクの開いた手アイコン**（白縁）に置換 = globe が draggable である合図。常時画面中央付近を移動（f049/050 で形状明瞭）。

### PiP 動画カード（右下）
- 位置 x≈78–95% / y≈78–95%、角丸、caption「**Shopifyが開発されるまで**」+ 丸 play アイコン。全 frame で常駐。
- 中身は autoplay のモンタージュ（工房→目のクローズアップ→人物ポートレート→室内→ピンク照明の人物、約 1–1.5s ごとにカット）。
