## 2. モーションの質

| 要素 | 質 |
|---|---|
| 頁遷移 §11→§12 | **純粋な scroll 移動のみ**。fade / scale / crossfade は検出されず。§12 見出し・本文も scroll とともに下から入るだけ（独立の entrance アニメ無し） |
| 浮遊サムネ（§11） | 静止時 idle アニメ **無し**（f001–005 diff = 0）。scroll 時は本文と**同速**で上へ（列別 shift 測定で 159/91/59px 一致 → **parallax 無し**）。§12 表示域まで被って残る = section 跨ぎの装飾レイヤー |

| globe 入場 | scroll 連動で下端から rise。入場時点で既に弧・夜景・自転が動いている（≒ 常時稼働の canvas を scroll で覗く構図） |

## 3. §12 globe 詳細

### 外観・配置（f027 settled 時点）
- 球: 中心 ≈ (20%, 65%)、可視域 x 0–55% / y 5–100%（左下に大きく食い込み、下と左は frame 外）。半径 ≈ frame 幅の 40–45%
- 配色: 海 = ほぼ黒の dark navy / 陸 = 明るめ teal-green の**粒状 speckle テクスチャ**（ドット質感）/ 都市光 = **暖色オレンジ〜金の点クラスタ**（日本・韓国・中国沿岸・東南アジア・インドが明瞭）
- 背景: 深緑黒 + まばらな白い星点
- 右列 text: 見出し x 64–87% / y 38–65%、本文 y 67–85%

### 自転
- **陸地が画面 右→左 へ等速 drift**。f025→f027（page 静止区間 0.5s）でカムチャツカ半島輪郭が **約 10px 左移動 = 約 20px/s**（900px 幅基準）→ 角速度 ≈ **1.5–2°/s** のゆっくり自転
- globe 自体の平行移動は無し（右 limb エッジ位置は f025/f027 で不動 → 移動は表面の回転）

### 弧（arc）
- 色: **白熱（warm white）**、先端が最も明るく、発着点近傍に金色 glow
- 描画方式: **彗星型セグメント** — 全長を描き切らず、先頭が伸び・尾が dash/粒子の鎖として減衰消滅しながら軌道上を走る。発射直後は破線の連なりとして立ち上がる（f023 左側 crop で確認）
- 軌道: 都市光から発射し、球面より高い 3D 放物線を描いて別都市へ着地。画面を横切る大円規模の長弧と短い跳ね弧が混在
- 頻度: 同時可視 **4–8 本**（f022 ≈ 5–6 本、f027 ≈ 8 本+）。連続 spawn、1 本の寿命 ≈ 1–2 秒。globe 入場時（f013）から常時稼働

### tooltip / 統計カード（この clip 内）
| 出現 | 位置 | 内容 |
|---|---|---|
| f022 (5.5s) | 画面左端・下寄り（x 0–10%, y 88%〜、左に見切れ） | 大きな counter 数字「#,###,###,###」+ 添え書き「（現在も増加中）」— 桁の多い累積 counter |
| f022 (5.5s) | 画面下中央（x 33–73%, y 95%〜、下に見切れ） | 角丸カード: 緑の storefront アイコン +「数百万社」+ 2行目（マーチャント数の説明）。crimson の小 pill 付き |

- globe hover での pointer tooltip はこの範囲では未発生（f026 で grab cursor 化までで clip 終了。drag / hover tooltip は f028 以降）

## 5. 再現実装への示唆

1. §11→§12 は**仕掛けゼロの素直な scroll**。価値は (a) section を跨いで残る浮遊サムネレイヤー、(b) 常時稼働 globe を scroll で「覗かせる」入場、の 2 点
2. globe は「scroll 到達で再生開始」ではなく**常時アニメーション**（入場 frame で既に弧が飛んでいる）
3. 弧は静的な path 描画でなく**先端伸長 + 尾の減衰**（dash-offset / particle trail 系の実装）
4. 統計は数字を直書きせず **counter（増加中表記）+ アイコン付きカード**として globe の縁に係留
5. custom cursor 3 態（I-beam / arrow / grab）が「触れる globe」の affordance を担う
