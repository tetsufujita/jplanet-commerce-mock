## モーション所見

- **核となる演出 = 2 段階の zoom-out reveal**。①単体 chat → phone frame fade-in で「文脈の付与」（f059–062, ~1.0s）、②phone → 多数 phone の collage で「規模の提示」（f070–075, ~1.5s）。どちらも scale tween + 周辺要素 fade-in の組合せで、カット割りなしの連続カメラ感。
- **sheet 遷移は全部 bottom slide-up**（詳細 ~0.5s / 確認 ~0.25s）。checkout の入力ステップは見せず、詳細→「Thank you」へ直結＝デモの编集で摩擦を消す。
- **typewriter は caption のみ**（~1.0s）。chat 文面はタイプ演出なしで fade。
- **collage の奥行きは scale 差 + 明度差 + 異速度 drift** で擬似 3D（実 3D 回転はなし、phone は全て正面向き）。
- 右下隅（x88–100% y93%以深）に常時別 media が crossfade で巡回（室内→街→人物の顔）。§3 動画外の隣接カード or 動画自身の next-scene 先出し。再現時は無視可。
- Shopify ブランド色は確認ボタンの **Shop 紫** のみ。残りは dark green 背景 + 白 UI。

## Andes 再現への示唆

- §2 chat デモに直移植可能な文法: 「caption typewriter → scale-down + frame fade-in で device 文脈付与 → sheet slide-up で購買完結 → dolly-out collage で規模提示」。Motion(`motion/react`) の scale/opacity tween + layout animation で実装可、3D 不要。
