## ③ 実装方針

### カード 1 全面作り直し — `ChannelsMock` → `ChannelsGraphMock`

```
構造:
  - 最上部: 商品カード浮遊エリア（absolute配置）
  - 中段: 中央ロゴ（Shopify相当 → konoha S バッグ型 SVG/div）
  - 中段→下: 接続線 SVG（中央ロゴの下端から各アイコンへ分岐）
  - 下段: 7 アイコン 2 列（左 3 = 丸形 / 右 4 = 角丸矩形）
```

**アイコン輝度パルス**: `useStageTimeline` を使用（7 stage × 500ms = 3500ms ループ）。
各 stage で対象アイコンのみ `brightness: 1.4 + opacity: 1.0`、その他は `brightness: 0.7 + opacity: 0.6`。
`motion.div` の `animate` prop で各アイコンを個別に制御。

```tsx
const ICON_STAGES: TimelineStage[] = [
  { key: "pinterest", ms: 500 },
  { key: "instagram", ms: 500 },
  { key: "google",    ms: 500 },
  { key: "ebay",      ms: 500 },
  { key: "tiktok",    ms: 500 },
  { key: "amazon",    ms: 500 },
  { key: "youtube",   ms: 500 },
];
// useStageTimeline(ICON_STAGES) → stageKey で active アイコンを判定
```

**商品カード浮遊出現**: `useStageTimeline` または独立 `setInterval`（≈8000ms 周期）で
`AnimatePresence` + `motion.div` の `initial={{ opacity:0, scale:0.85, y:8 }}` → `animate={{ opacity:1, scale:1, y:0 }}` → `exit={{ opacity:0, scale:0.9, y:-4 }}`。
表示時間 1500ms、transition duration 0.35s。

**接続線**: SVG `<line>` / `<polyline>` で中央ロゴ下端 → 各アイコン中央へ直線。
stroke は `rgba(255,255,255,0.12)`、active アイコンへの線のみ `rgba(255,255,255,0.4)` に連動変化（motion で animate）。

### カード 2 そのまま維持 — `PosMock`

差分は軽微。`PosMock` は既に本家の静止挙動と一致しており変更不要。

### カード 3 要修正 — `CheckoutFeedMock` → 静止 checkout UI に差し替え

本家の実態は checkout UIカードの**静止表示**のみ。縦スクロール feed を削除し、以下の静止構造に置換:

```tsx
// 静止 checkout UI モック
// - 「注文サマリー ^」見出し（右端に $125.00 相当の金額）
// - サムネ + 商品名（フォレストニットセーター Sサイズ）+ 価格（¥19,000）
// - クーポンコード欄 + 適用ボタン
// - 小計 / 配送料 / 推定税額 / 合計 の明細行
// - 「今すぐ支払う」CTA ボタン（Shopify グリーン系）
// → アニメなし。AnimatePresence / motion.div 不使用で良い
```

`useReducedMotion` 分岐も不要になる（静止のため）。上下フェードは維持可。

## ④ 必要アセット

### 商品カード用サムネ

`public/shopify-jp/knit-*.jpg` に以下が存在:
- `knit-camel.jpg` `knit-chair.jpg` `knit-flat.jpg`
- `knit-model-close.jpg` `knit-model.jpg` `knit-still-black.jpg`

本家の商品カードは白背景に衣類全体を映したシルエット風の小サムネ（黒系ニット）。
**`knit-still-black.jpg` または `knit-flat.jpg` が最も近い**。既存アセットで対応可。

サイズは `w-[40px] h-[40px]` 前後の正方形トリミングで十分。

### チャネルアイコン

本家ロゴ（Pinterest/Instagram 等）は複製しない。代替:

| 位置 | 色・形の役割 | 実装案 |
|---|---|---|
| 左上（丸・赤系） | 赤 #E0484E 系 + 白グリフ（Pマーク） | `bg-[#E0484E] rounded-full` + 白 SVG |
| 左中（丸・グラデ） | ピンク〜橙グラデ（カメラ型） | CSS radial + `rounded-full` |
| 左下（丸・青系） | 青 #4285F4 系 + GロゴSVG | `bg-[#4285F4] rounded-full` |
| 右上（角丸・マルチカラー） | 赤/青/黄/緑4分割 | `rounded-md` + CSS grid 4 色 |
| 右中（角丸・黒） | 黒地 + 白音符グリフ | `bg-black rounded-md` |
| 右下（角丸・濃紺〜黒） | 濃紺 + 白サーフェス型テキスト | `bg-[#1a1f2c] rounded-md` |
| 右下2（角丸・赤） | 赤 #FF0000 + 白再生ボタン | `bg-[#FF0000] rounded-md` |

既存アセットに追加不要。すべて CSS + 既存 lucide アイコンで代替可能。

### 中央ロゴ（Shopify バッグ型）

架空ブランドの代替として: `konoha` の緑系バッグ型 SVG（簡易 path）を `src/shopify-jp/` に追加するか、lucide の `ShoppingBag` を `text-sp-avocado` でラップ（サイズ 40×40）でも十分な再現度。

## サマリ（3 行）

**差分件数**: 合計 7 件（カード1 = 4件・カード2 = 0件・カード3 = 3件）、うち要対応高優先度は 4 件。

**カード 1（あらゆるチャネルで販売）**: 本家は「中央ロゴ + 7 アイコン接続図 + アイコン輝度パルスループ + 商品カード浮遊出現」の組み合わせ。現実装（SNS feed 縦スクロール）とは**構造から完全に異なり全面作り直し必要**。
