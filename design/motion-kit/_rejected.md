# _rejected — 入れない effect と理由（盛りたくなったら見る）

> このファイルが slop を物理的に止める。「かっこいい気がする」effect を足したくなったら、まずここに却下理由が無いか見る。

| 却下した effect | 理由 |
|---|---|
| globe / cosmos / 大きな地球デモ | reset 2026-06-04 で廃案。`_archive/` 参照。"巨大な白い地球デモ" を sir が不採用 |
| commerce rail / 立ち上がる layer 演出（過剰版） | hero 主役を奪う・slop 化。s1 は宣言 reveal + line 1 本のみ |
| 背景の動く gradient（全面）/ Stripe-mesh / 紫・青・レインボー | 第2色追加＝slop 筆頭。色は Crimson のみ pin-point |
| 過剰 parallax（全面）/ scroll スクラブの演出過多 | once 原則を破る・酔う。docs/04 NG |
| cursor 追従要素 | コーポレートで方向性を失う |
| 自動 carousel / 数字の常時ループ / 動画背景 | 落ち着き・信頼を毀損 |
| 3D 抽象人間 / glowing orb / floating UI を持つ手 | 2026 AI slop の典型 |
| Aceternity aurora / 3D card / v0 生出力の無改変 | "見たことある AI サイト"＝即 slop 認定 |
| BGM / 音 | コーポレートに不要 |
| section ごとに別の easing | 一貫性崩壊＝premium が消える。唯一 token（00_tokens）を使う |
| 動かす section を 4 つ以上 | motion budget 超過。最大 3（hero/数字/2層）+ §5 図 draw まで |

**集めたくなったら**: 「IA のどの section の、どの要件を満たすか」を言えない effect は入れない。言えるなら motion-kit に 1 entry 追加（手本 1・付け方 3 点セット付き）。
