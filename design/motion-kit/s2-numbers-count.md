# s2 — 4 マクロ数字の count

- **要件**: 6.6億人 / US$7,690億 / 2.1億人 / 1.7億人 に「重み」を与え、市場の大きさを信頼として刻む。
- **手本（1 サイト）**: **dLocal**（越境 infra の数字章＝最も近い意味文脈。静かに上がって止まる）。
- **付け方**:
  - なぜ: 数字に重み（infra の信頼感は「静かに上がって止まる」が正解）。
  - どこで: §2 の各数字、in-view。
  - いつ: 画面内に入ったら **1 回**（once）。
- **抑制**: `--dur-count`(1200ms) / ease=`--ease-andes`。派手にしない。
- **実装**: 既存 `src/components/motion/CountUp` or 既導入 `@number-flow/react`（桁送りが綺麗）。**接尾辞（億人 / US$ / 兆）を壊さない**（i18n）。出典ラベルは monospace で静止。
- **反例**: carousel / 各数字を別 ease / 常時ループ / count を毎スクロールで再生。
- **reduced-motion**: 最終値を即表示。
