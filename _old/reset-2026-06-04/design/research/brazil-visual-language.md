# Brazil Visual Language

> Hero/early に Brazil/São Paulo を**上品に**出す。観光でなく**商取引インフラ**を visual grammar に。
> 原則: 色は2つ（近黒+Crimson #C8102E pin-point）。**各システムの色・ロゴは一切 borrow しない**。地域は「装飾」でなく「住所・固有名・出典付き数字・インフラの motion」で接地する。
> 全候補 fetch 実在確認（一部 bot ブロックは search 確認、末尾に明記）。

## 核心の発見（3 つ）
1. **SISCOMEX 通関 gate motion = moat の唯一の可視化**（他社が真似できない Andes 固有の強み）。
2. **São Paulo 都市光 = Black Marble の luminance を抽出 → 近黒→Crimson に単色 re-map**（生 RGB の黄橙は貼らない）。
3. **一流 BR 企業は全社、国旗色を自社固有色に置換し、地域は統計＋法人番号で接地**（Nubank/dLocal/Stripe BR/Creditas）。我々の Crimson 戦略はこの系譜。

## ✅ 採用すべき Brazil 表現 10

### 1. 固有インフラ名の「一語接地」（ロゴなし・monospace）
ダーク画面に地図を盛らず、`PIX` `NF-e` `SISCOMEX` `BACEN` のような固有名を **monospace で 1 語** pin-point 表示。CloudWalk/InfinitePay 流。装飾ゼロのまま土地が立つ。
> ⚠ public copy 注意: 「PRC 唯一の日本企業」「24ヶ月先行」等は **public NG**（docs/02・memory）。インフラ名の提示は可、moat の機密 framing は出さない。

### 2. 法人実在で接地（CNPJ ＋ Av. Paulista 2300 ＋ pt-BR 法人名）
footer/About に J-Planet の実 CNPJ **`63.097.119/0001-44`**（docs/01・架空厳禁）＋ `Av. Paulista, 2300` ＋ pt-BR 法人名を控えめに。Stripe BR/Creditas 流。「本当にそこに登記され、根を張っている」を観光ゼロで証明。

### 3. 出典付きマクロ数字を「光点のデータラベル」に
4 マクロ数字を地図装飾でなく日本⇄ブラジル光点に紐づく**出典付きラベル**で: 6.6億人 (World Bank) / US$7,690億 (PCMI) / 2.1億人 (IBGE) / 1.7億人 (中銀)。dLocal/EBANX/MELI 流「地域＝検証可能データ」。出典名併記で investor-grade が一段上。

### 4. 国旗色を Crimson に置換（緑黄ゼロ）
地域の気配は **Crimson #C8102E の pin-point ＋ pt-BR の一語**だけで出す。緑・黄は一切使わない（Nubank が violet で実証、docs/04 色 lock の裏取り）。

### 5. PIX 即時パルス（teal 不使用）
即時決済を **ノード A→B を Crimson の光点が一瞬で走る** motion（0.2–0.3s ease-out・残光なし）。PIX の teal `#32BCAD` は使わず、菱形 ◇ を 1px 線で極小に抽象継承するのみ。「即時 = Andes の動脈」。

### 6. ★SISCOMEX 通関 gate（moat の可視化）
日伯 arc が国境を横切る所に**複数の極細縦 gate（通関 / ANVISA / SISCOMEX）が並び、粒子が順に Crimson 点灯で滑らかに通過**。Andes が「全 gate を通せる」を motion で。**このレンズ単独最強・他社が真似できない**。gate を障害でなく「滑らかに通す」ポジティブに。

### 7. compliance スタック（LGPD·ANPD ＋ CNPJ を z-depth 薄板）
arc/agentic の光が走る土台に、**半透明の薄板を z 方向に数枚重ねる depth strata**（物流 / 税 / 法 / 通関 = 1 板 1 概念）。frosted glass、端の hairline だけ Crimson、`LGPD · ANPD` `63.097.119/0001-44` を monospace 極小。「規制の上で動く = trust」を地味に。GSAP/ScrollTrigger で下から積層。

### 8. NF-e 発行ノード（一瞬のチラ見せ）
取引成立ごとに**小さな矩形ノードが fade-in し、44 桁 access key が一瞬立ち上がって消える**。背景に帳票グリッドの極細罫線を texture として薄く。「政府が認可した legitimacy」を data layer の信頼感に。全桁は読ませない（一瞬だけ）。

### 9. São Paulo 収束ハブ（Av. Paulista hairline ＋ 座標）
arc が地球上で **São Paulo の一点に収束 → 近黒の都市 grid が薄く広がり、Av. Paulista を Crimson の hairline 1 本だけで主軸化**。座標 `-23.56, -46.65` を monospace で静かに。FIESP（黒ファサード・夜 LED）の「暗い面に灯る微光」を抽象継承（建物はトレースしない）。

### 10. São Paulo 都市光（Black Marble の単色 re-map）
globe 降下時に São Paulo が「灯る」瞬間を、**NASA Black Marble（実測夜景・public domain）の luminance だけ shader で抽出 → 近黒→Crimson の単色ランプに再マップ**。生 RGB（黄橙）は絶対貼らない。東京・São Paulo の 2 点だけ発光、他は無発光で 2 色原則を球面全体で貫く。

## ❌ 避ける Brazil cliché 10

1. **国旗カラー全面 / 緑黄 gradient**（一流 BR 企業は全社回避。禁止リスト直撃）
2. **Christ the Redeemer / 名所 skyline / landmark シルエット**（QuintoAndar は landmark を捨て地区名テキストに）
3. **carnival**（祝祭演出は investor 信頼を下げる）
4. **soccer を色で国旗化**（使うにしても緑黄にしない）
5. **generic happy people stock photo**（感情演出でなく出典付き統計＋法人番号で legitimacy）
6. **travel/tourism 感の彩色 realistic 地図**（地図は簡略幾何 or 光の経路に機能化）
7. **"Latin America" の一括ぼかし**（MELI は国を名指し差を数字で。まず日本⇄ブラジルを具体化）
8. **システムロゴのトレース/流用**（PIX モザイク・Correios 地球儀・Drex 矢印 = 剽窃＋ダサい。抽象モチーフだけ継承）
9. **システム色を画面に乗せる**（PIX teal / Drex 青→緑グラデ / Correios 黄。色は一切 borrow しない）
10. **generic アイコン slop**（security 盾・鍵 / web3 hexagon・チェーン / 税関スタンプ / バーコード主役 / DANFE・boleto の実物画像貼り / 44 桁全見せ / **架空 CNPJ**）

## 実装メモ
- globe: cobe（Hero・5KB）/ three-globe（corridor arc・`arcDashAnimateTime`・着弾 `rings`）。São Paulo 都市光は Black Marble 南米 crop を luminance 抽出 shader で（生 RGB 不可）。
- strata: 薄板 z-depth は GSAP+ScrollTrigger or SVG parallax、frosted glass（backdrop-filter / three transmission）。reduced-motion は最初から静止積層。
- 全 motion は MotionGate（prefers-reduced-motion）配下、mobile は arc/disc 数を絞る。
- ⚠ `[unverified]`: PIX 公式色 `#32BCAD` は公式 PDF 未パース（どのみち不使用なので影響なし）。CNPJ は必ず docs/01 実値。
