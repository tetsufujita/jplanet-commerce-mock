The Core

まず頭に入れる 9 法則

サイトを真似る前に、これを内面化する。配色・没入・語りの 3 系統、各 3 法則。

配色・質感

01

accent は「面積」で殺す。一流ほど brand color を CTA と強調語だけに限定。色は足すほど安い。＝ Crimson pin-point が正解。

02

premium は色でなく type と余白で。size・weight・余白の差だけで上質を作る。装飾（紫グラデ）に逃げない＝引き算。

03

dark は色でなくコントラストと陰影で。vibrant 色を足さず overlay と soft shadow で奥行き（Retool / Linear）。

没入・モーション

04

没入は scale + 余白 + 段階開示で。motion の量で作らない（Apple / Linear）。scroll-jacking は制御を奪い restrained を壊す。

05

強い効果は 1 箇所に絞る = pin-point。magnetic cursor も流体も Crimson も「全面でなく要点」。

06

重くても性能と reduced-motion を死守。Igloo は LCP≈1 秒・テクスチャ圧縮・fallback。これが上質と自己満を分ける。

語り・コピー（見せ方）

07

hero は宣言、proof は具体数値。抽象主張は具体数字（before/after・巨大数・実名）で裏取り。4 マクロ数字はこの型に。

08

宣言の直後に地味な実装を併置。経済を作り替える→物流・税・法を一つずつ繋ぐ。壮語を具体で着地させる。

09

時間軸の壮大さは数字でなく対句で。「Insights today. Impact for generations.」$1T・100 年は数字で出さず対句に翻案。

Lens A

B2B / infra 一流

型・余白・抑制。色に頼らず size と weight で premium を出す象限。

Stripestripe.com
結果先行の宣言 hero。巨大 bold 数字＋小注釈の proof。accent は CTA だけ。
学び: 宣言型 hero の語順（結果→説明）。4 マクロ数字を「数字＋極短ラベル」で。
#宣言型hero#色の抑制#proof
Linearlinear.app
色に頼らず size/weight だけで階層。事業を block 分割グリッド。
学び: restrained premium の核。proof は数を盛らず 1 強数値＋実名。
#タイポ#グリッド#余白
Anthropicanthropic.com
mission 先行宣言。色を足さず権威。教育的・非攻撃トーン。
学び: 「Anthropic 声」原典。mission を hero に置く型が直接当たる。
#トーン#宣言型hero
Sierrasierra.ai
行分割の宣言文。text/image 交互レイアウトで section をリズム化。
学び: 「Sierra motion」原典。交互レイアウトで呼吸を作る。
#宣言型hero#余白#proof
Vercelvercel.com
proof を before/after 具体数値（build 7m→40s）。高コントラスト neutral。
学び: 抽象主張より before/after 数値が説得力。CTA は短く事務的。
#proof#色の抑制
Mercury / Retool / Browserbase+3
fintech の信頼×モダン / dark の正解（色でなくコントラスト）/ agent 文脈の能力宣言。
学び: accent を CTA と強調だけに限定する面積管理。生の巨大数字で scale。
#色の抑制#ダークモード#proof
Lens B

シネマティック / 没入

restrained に効くものだけ。やり過ぎは反面教師として残す。

Apple — AirPodsapple.com
scroll-scrub の startframe→endframe。scale+余白+段階開示で支配。
学び: 最重要手本。motion でなく scale で premium。数字 reveal に直接転用。
★手本#scroll-scrub#restrained
Igloo Incigloo.inc
1 つの抽象オブジェクトに事業を内包→scroll で reveal。LCP≈1 秒死守。
学び: 純抽象 IA に直結。重くても性能・reduced-motion を守る規律。
★手本#WebGL#performance
Obys Agencyobys.agency
文字組み/グリッドが主役、WebGL は脇役。letter で没入。
学び: 過剰な 3D に頼らず文字組みで没入＝宣言型 hero と一致。
★手本#letter-motion
Lusionlusion.co
cursor 追従の流体（three-fluid-fx hero の手本）。全面 WebGL。
学び: 流体は手本だが Andes は hero 局所に留める。全面は過剰。
#fluid⚠過剰注意
Active Theoryactivetheory.net
hover で隣を 2px ずらす rack focus（低コストで上質）。
学び: その micro 技法だけ盗む。全面 3D 空間は方向性を失う反面教師。
#micro-interaction⚠過剰注意
Cubertocuberto.com
magnetic cursor（CTA 1 箇所だけ効かせる）。
学び: pin-point 同型＝効かせる場所を絞る。skew まではやり過ぎ。
#cursor⚠遊びすぎ注意
Lens C

見せ方 — 語り・コピーの型

ビジュアルより「どの順で何を見せ、どう説得するか」。実 copy 引用（原文＋訳）。

MercadoLibreinvestor.mercadolibre.com
★最重要参照 — 地域 No.1 宣言 → 長期視点で短期不安を上書き
“The Leading Commerce and Fintech Ecosystem in Latin America” / “Our Long Term View in 5 Charts”
中南米を牽引するコマース＆フィンテックのエコシステム ／ 5 つのチャートで見る我々の長期視点。EC 市場 $151B(2023)→$232B(2028)。
Andes → 「US$7,690億」を成長トレンドの文脈に。「Long Term View」は 100 年スパンの上品な語彙。
Watershedwatershed.com
対句の短文で壮大さと品位を両立
“Insights today. Impact for generations.”
今日に洞察を。世代に影響を。（対句・体言止め）
Andes → 「[今/具体] と [世代/壮大]」の 2 文対句で、100 年スパンを数字を出さず匂わせる。
Anthropicanthropic.com
信条宣言 → but 節で謙虚さを担保
“AI research and products that put safety at the frontier.”
最前線に安全を置く AI の研究とプロダクト。「恩恵を確かにし、リスクを抑える」と併置。
Andes → 壮語の直後に地味な実装を併置（経済を作り替える→物流・税・法を一つずつ繋ぐ）。
Nubankinternational.nubank.com.br
包摂率でインパクトを定量化
“62% of Brazilian adults are customers.”
ブラジルの成人の 62% が顧客。初めてのクレカを Nu で得た人 2,800 万人。mission「fight complexity and empower people」。
Andes → 「2.1億人/1.7億人」を規模でなく「これだけの人の経済基盤になる」意味に転化。
Stripestripe.com
カテゴリ宣言 → 射程を広げる三段 → 数字で規模保証
“事業成長を支える金融インフラ。”
sub:「決済 → 組込み型金融 → エージェンティックコマースまで」（射程を広げる三段）。135+ / $1.9兆 / 99.999%。
Andes → 「中南米に新しい経済の基盤を建てる」+ sub で射程三段。4 数字は極短ラベルで並置。
