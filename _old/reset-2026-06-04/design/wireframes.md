## Mobile（参考）

```
desktop の各 section は mobile では以下のルールで簡略化:

  Hero        : viewport 高さ 80vh、text のみ、visual は背景に薄く
  3-card      : 1 列縦並び（gap 24px）
  2-column    : 1 列縦並び（text 上、visual 下）
  Header nav  : hamburger menu、開くと full-screen overlay
```
