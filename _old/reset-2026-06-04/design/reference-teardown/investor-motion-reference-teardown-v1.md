# Investor Motion Reference Teardown v1

This is a study file. It is not a copying brief. Each reference is reduced into transferable craft principles for Andes.

## 1. Apple Product Narrative

Reference: https://www.apple.com/airpods-pro/

### What It Does Well

- Treats the page as a sequence of shots, not components.
- Lets one dominant object carry multiple sections.
- Uses scroll as camera movement.
- Reveals copy after the visual has already created curiosity.
- Uses darkness, scale, and negative space to create importance.

### Transferable DNA

- One hero object.
- Camera-like transitions.
- Sparse text.
- Reveal only when needed.
- The final still image matters as much as the motion.

### Andes Translation

The dominant object should be a living trade corridor / infrastructure graph, not a grid of cards. The page should feel like the camera moves through the system: corridor -> friction -> platform -> rails -> protocol.

### What Not To Copy

- Apple product gloss.
- Consumer product intimacy.
- Hardware-render centered staging.

## 2. Stripe Infrastructure Design

Reference: https://stripe.com/

### What It Does Well

- Makes infrastructure feel understandable without making it small.
- Uses complex systems as elegant surfaces.
- Pairs huge ambition with operational specificity.
- Uses accent color sparingly.
- Converts complexity into trust.

### Transferable DNA

- Dense business logic becomes clean infrastructure.
- Use real rails, not decorative diagrams.
- Proof and scale must sit close to claims.
- Avoid over-explaining with paragraphs.

### Andes Translation

Andes should show tax, logistics, customs, payments, and legal rails as a coherent infrastructure layer. It should not show generic "AI shopping" UI as the main proof.

### What Not To Copy

- Stripe-like gradient surfaces.
- Stripe checkout/payment visual vocabulary.
- Generic global-commerce copy without Andes' Brazil-specific moat.

## 3. Linear Product-Quality Restraint

Reference: https://linear.app/

### What It Does Well

- Every surface feels intentional.
- Spacing and hierarchy do the premium work.
- Motion is quiet but exact.
- Components do not fight for attention.
- The interface feels engineered, not decorated.

### Transferable DNA

- Fewer objects per viewport.
- Hard hierarchy.
- Quiet interaction.
- Avoid equal-weight cards.

### Andes Translation

Andes frames should have one visual center. If a frame contains too many nodes, labels, and badges, it becomes weak. The corridor/platform/protocol object must be the visual center.

### What Not To Copy

- Software-product dashboard mood.
- Dev-tool minimalism that loses market scale.

## 4. Anthropic Mission Gravity

Reference: https://www.anthropic.com/

### What It Does Well

- Creates seriousness with restraint.
- Lets the mission lead.
- Avoids toy metaphors for AI.
- Builds trust through language and silence.

### Transferable DNA

- Say the important thing plainly.
- No gimmick AI visuals.
- Institutional tone.
- Whitespace as authority.

### Andes Translation

Andes should not show cartoon agents, chat bubbles, or futuristic gimmicks. The agent should feel like an interface to a serious economic layer.

### What Not To Copy

- Overly calm academic minimalism that makes Andes feel less ambitious.

## 5. Sierra Narrative Sections

Reference: https://sierra.ai/

### What It Does Well

- Uses bold narrative pacing.
- Makes customer experience feel like an operating system.
- Alternates large claims with tangible moments.
- Gives each section a single job.

### Transferable DNA

- One idea per section.
- Section as chapter.
- Product concept revealed through staged scenarios.
- Visual rhythm changes as the story progresses.

### Andes Translation

Each Andes scene needs one investor takeaway:

- This is a continental opportunity.
- The friction is real.
- Andes already operates in the market.
- The platform layer is the moat.
- The wedge expands into rails.
- The rails become protocol infrastructure.

### What Not To Copy

- Sierra's rounded cards.
- Customer-support SaaS framing.
- "Helpful AI agent" softness.

## 6. Igloo / Active Theory Cinematic Systems

References:

- https://igloo.inc/
- https://activetheory.net/

### What They Do Well

- Use depth and motion to make abstract systems feel physical.
- Make one object or scene carry the brand mood.
- Treat WebGL as atmosphere and structure, not decoration.
- Create memorable visual moments through lighting and movement.

### Transferable DNA

- Abstract object as brand carrier.
- Depth before decoration.
- Motion rhythm matters more than number of animated elements.
- Performance and restraint keep the work premium.

### Andes Translation

The Andes object could be a corridor/platform graph with depth: fragments in the foreground, rails in midground, protocol graph in background. This can become Remotion first, then WebGL/scroll later.

### What Not To Copy

- Agency-site spectacle.
- Interaction for interaction's sake.
- Overly playful or exploratory navigation.

## 7. Core Lessons For Andes

### Lesson 1: Do Not Start With A Section Layout

Start with a shot:

- What is the dominant object?
- What is the camera doing?
- What changes?
- What does the investor understand?

### Lesson 2: One Object Per Frame

Every frame needs one visual object strong enough to remember:

- corridor
- friction field
- order path
- platform layer
- expansion rail
- protocol graph

If the frame is just text and labels, it fails.

### Lesson 3: Material Before Geometry

Geometry alone looks like a consulting slide. Andes needs material:

- regulatory fragments
- shipping fragments
- commerce order fragments
- entity proof
- product origin metadata
- map/geography

### Lesson 4: Motion Must Explain The Business

Acceptable motion:

- corridor line establishing market route
- fragments failing to align
- platform absorbing fragments
- agent layer separating from infrastructure layer
- rails expanding
- graph simplifying

Unacceptable motion:

- random fades
- decorative parallax
- floating labels with no transformation
- card reveals

### Lesson 5: Build One Excellent Frame First

Do not create six more frames yet.

The next design task should be Frame A only:

- one dominant visual object
- material specificity
- investor scale
- Remotion-ready motion path
- beautiful as a still

## 8. New Andes Frame A Brief

Working title: "The Corridor Becomes Infrastructure"

The frame should show:

- a dark or paper field with cinematic depth
- Japan/Korea origin and Brazil/Sao Paulo destination
- the route is not a simple line; it is a system corridor
- tiny operational fragments sit along the route
- the corridor begins to resolve into rails/platform geometry
- copy is secondary to the visual

The viewer should feel:

- this is cross-border but larger than logistics
- this is AI-era commerce but not a chatbot
- this is an infrastructure company, not a store

If the frame cannot be remembered as an image, it fails.
